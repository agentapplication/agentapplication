> **Agent Application Platform** turns tested Agent Projects into immutable
> releases and operates long-lived instances with durable workspaces, identity
> management, security controls, governance, observability, evaluation, and
> fleet management.

The platform turns a framework-native project into an operating product. It
resolves and verifies dependencies, packages the complete graph as an immutable
release, creates instances at the application's privacy boundary, attaches a
durable workspace and scoped authority, and runs the sessions that perform the
work.

In the paper's seven-layer stack, L5 is the Agent Application Platform. A
platform may also provide development tools for creating and testing the
framework-native L4 Agent Application Project. The optional L6 Agent
Application Store handles acquisition, entitlements, billing, publisher
payments, and monetization.

It also supplies shared services for identity and authority, scheduling, event
delivery, artifacts, evaluation and observability, governance, fleet upgrades,
cost allocation, and usage enforcement.

## Agent Cloud and platform

Ordinary cloud infrastructure provides compute, storage, networking, and
databases. [Agent Cloud](/concepts/agent-cloud) adds infrastructure for
persistent agents, including durable workspaces, resumable execution, sandboxed
tools, checkpoints, and per-instance metering.

An Agent Application Platform is the larger product layer. It may use an Agent
Cloud, provide those services itself, or assemble them from ordinary cloud
services.

See the paper's [Agent Application Platform](/paper#18-the-agent-application-platform)
and [Agent Application Store](/paper#21-agent-application-stores) sections.
